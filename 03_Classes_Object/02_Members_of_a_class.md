# Members of a class

### Variables

Multiple variables declaration

```java
int i, j;

```

Multiple variables initialization

But during initialization only the first one is initialized. So in below code i is not initialized and if try to do any operation with i it will not compile and give error

```java
int i, j =3;
System.out.println(i + j);  // i not initialized and will give error

```

To initialize both must do like this

```java
int i=3, j =3;
//or 
int x, y, z;
x = y = z = 22;

```

If you assign value while declaring variable then all copies of the object will have same values, otherwise it will have default value.

```java
public class Test {

    int i = 3;
    int j;

    public static void main(String[] args) {
        Test test1 = new Test();
        Test test2 = new Test();
        System.out.println("Test object i value --> "+ test1.i + " "+ test2.i);
        //Both object have same value for i =3 which was declared
        System.out.println("Test 2 -->"+ test1.j + " "+ test2.j);
        //Both object have same value value for j =0 which is default
    }
}

```

### Constructors

A constructor tells how the object of a class will be instantiated and with what values. It can be tedious to initialize all the variables in a class each time an instance is created. So, we can assign the values during object creation.

```java
public Box(int height, int width, int length) {
    this.height = height;
    this.width = width;
    this.length = length;
}
Box b1 = new Box(4,5,6);

```

Constructors can have any kind of identifier public, private, protected, default. But constructors mostly used public. So that other classes can initialize them

Constructors look a little strange because they have no return type, not even void. This is because the implicit return type of a class’s constructor is the class type itself.

When you do not explicitly define a constructor for a class, then Java creates a default constructor for the class. Which is no argument constructor.

But if a contractor is already declared then no argument constructor will not be generated by default. So below will not compile as we have defined  a constructor with arguments and no default constructor

```java
public class Test {
    public static void main(String[] args) {
        Box myBox = new Box();          // will not compile as it needs default constructor
    }
}

class Box {
    int height,breath, length;

    Box(int height, int breath, int length) {
        this.height = height;
        this.breath = breath;
        this.length = length;
    }
}

```

In this case will have to explicitly mention no arguments constructors.

```java
class Box {
    int height,breath, length;

    Box(){}

    Box(int height, int breath, int length) {
        this.height = height;
        this.breath = breath;
        this.length = length;
    }
}

```

### Instance Initialization/Code Blocks

Code blocks are piece of code which are executed when the class is instantiated. You can also create objects there.

Needed for

- Anonymous class which doesn’t have constructors to handle initialization logic.

- Also, if you have any common logic for multiple constructor you can keep in code blocks

```java
public class Test {
    static {
        System.out.println("Block 1");
    }

    {
        System.out.println("Block 1");
    }
}

```

Code blocks can also be static. Static blocks are loaded when the Class is loaded in JVM for the 1st time. When you initialize class again with new(), code block will not execute again. non-static code block will execute even time the class initialized with new

Let’s say we have a class Test2 with code blocks

```java
public class Test2{
    {
        System.out.println("This is non static block"); //Will execute before Main or anything.
    }
    static {
        System.out.println("This is static block"); //Will execute before Main or anything.
    }

    public Test2(){
        System.out.println("This is constructor");
    }
}

```

When we call it from test

```java
public class Test {
    public static void main(String[] args) {
        Test2 test2; // No code block will be called
        System.out.println("Initialized");
        test2 = new Test2(); //Both static and non-static block will be called
        new Test2(); // Only non-static block will be called

    }
}

```

- Duriung initialization no code block will be called

- When we initialize 1st time both static and non-static block will be called

- For subsequent initialization only non-static block will be called

- Constructors will be called after code blocks

When we are running static blocks for the class containing main, the static block will load at the beginning even before main is executed. Because class gets loaded. This is the only scenario where something gets executed before main

```java
public class Test {
    static {
        System.out.println("Block 1");
    }

    {
        System.out.println("Block 3");
    }

    Test() {
        System.out.println("This is constructor 4");
    }

    public static void main(String[] args) {
        System.out.println("main starting");
        Test t = new Test();
        new Test();
    }
}

```

### Order Of Execution

When any class is instantiated

- First any code block will execute e.g. “Block 1”.

- Static block is executed first then non static block. (Static block will execute when the class is loaded in JVM for 1st time, non-static code block will execute even time the class initialized with new )

- In case of multiple non static blocks, they are executed in the order they appear.

- Then constructor code will execute e.g. “This is box-no argument constructor”.

- Then any method is executed e.g., volume ().

- In case of static method call code, block and constructor is not called.

```java
public class Test {
    static {
        System.out.println("Block 1");
    }

    {
        System.out.println("Block 3");
    }

    Test() {
        System.out.println("This is constructor 4");
    }

    public static void main(String[] args) {
        System.out.println("Main 2");
        Test test = new Test();
    }
}

```
